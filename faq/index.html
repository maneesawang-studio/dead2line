Frequently asked questions

How do I add a task?

Open the Tasks page and select + Add. Enter a title and deadline; category, time, notes, and subtasks are optional.

How do I mark a task as finished?

Select the check button on a task card. Use the In progress and Finish tabs to switch between task lists.

What does the urgent label mean?

It marks an in-progress task whose deadline is within three days.

How do I change the theme or language?

Open the profile menu on the Tasks page, then choose a theme or switch between English and Thai.

How does sign-in work?

Sign-in uses Supabase Auth. Use the account created for this workspace.

Are my tasks saved to the cloud?

Yes. Tasks are stored in Supabase and protected by per-user access rules.
